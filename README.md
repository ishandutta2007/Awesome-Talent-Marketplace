> **🔥 What is a Talent Marketplace?** A talent marketplace is an AI-powered platform that matches employees to internal roles, projects, gigs, mentorships, and learning opportunities using skills inference, career-pathing logic, and semantic matching — unlocking internal mobility and reducing external hiring dependency.

This repository tracks notable **SaaS platforms** and **open-source projects** for **Talent Marketplaces**. Whether you're an HR leader, people analytics engineer, or developer building internal mobility tools, this list has you covered.

**🏢 Industry Leaders**: [Gloat](https://gloat.com/), [Fuel50](https://fuel50.com/), [Eightfold AI](https://eightfold.ai/), [Phenom](https://www.phenom.com/), [Workday Talent Marketplace](https://www.workday.com/), [SAP SuccessFactors](https://www.sap.com/products/hcm/successfactors.html), [50skills](https://50skills.com/), [Neobrain](https://www.neobrain.io/), [365Talents](https://www.365talents.com/), and [TechWolf](https://techwolf.ai/)

**💻 Open-Source Focus**: Fully featured enterprise-grade open-source talent marketplaces are rare. This section is expanded with the strongest available open-source skill-matching platforms, mentorship marketplaces, HR matching tools, and related projects that organizations can adapt for internal mobility use cases.

**💡 Keywords**: *internal talent marketplace, skills-based matching, employee mobility platform, career pathing software, workforce agility, opportunity marketplace, AI talent matching, skills ontology, internal gig economy, talent intelligence platform*

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

### 🚀 Additional Strong Open-Source Options

- 🌐 **Self-hosted job boards** built on open CMS or low-code platforms (e.g., WordPress + WP Job Manager, Django Job Board).
- 🕸️ **Graph databases** (Neo4j, Apache AGE) modeling people–skills–roles relationships for advanced matching.
- 📚 **Open learning platforms** (Moodle, Open edX) integrated with skills tagging for learning-to-opportunity pathways.
- 📄 **Employee profile and resume parsing libraries** (e.g., pyresparser, python-resume-parser).
- 🎯 **Recommendation engines** using collaborative or content-based filtering for internal opportunities (e.g., LightFM, Surprise).

### 🏗️ Building Your Own Talent Marketplace

**Frameworks for building custom systems**: Start with an open HR or profile system (Frappe HR, Horilla, or OrangeHRM), add a skills taxonomy (custom or via Skills-ML / Open Skills API), implement semantic matching with vector embeddings (Sentence Transformers, FAISS), and surface opportunities via an internal portal or chatbot. Use open workflow tools for applications and approvals, and feed results into analytics dashboards. This approach works well for mid-sized organizations or as a complement to existing HCM systems, though it lacks the deep enterprise skills inference, bias testing, and scale of commercial talent marketplaces.

## ⚠️ Disclaimer

- 📌 This is a **community-curated** list — not exhaustive and not an endorsement.
- 🔒 Talent marketplace systems process sensitive employee data and influence career opportunities. Open-source solutions provide transparency and ownership but require careful attention to data privacy, bias mitigation, access controls, and integration with formal HR processes.
